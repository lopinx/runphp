## 1. 安装

### 1.1 桌面端

#### Windows

1. 下载 `RunPHP_0.1.0_x64-setup.exe`
2. 双击安装（如提示 SmartScreen，点击「仍要运行」）
3. 首次启动后会引导下载 FrankenPHP 运行时（约 60MB）

#### Linux

1. 下载 `RunPHP_0.1.0_amd64.AppImage` 或 `.deb`
2. AppImage 方式：
   ```bash
   chmod +x RunPHP_*.AppImage
   ./RunPHP_*.AppImage
   ```
3. deb 方式：
   ```bash
   sudo dpkg -i RunPHP_*.deb
   ```

### 1.2 无头服务器

```bash
# 下载 CLI 二进制
curl -L https://github.com/lopinx/runphp/releases/latest/download/runphp-linux-x86_64 -o runphp
chmod +x runphp

# 安装运行时
./runphp runtime install 1.12.7

# 验证
./runphp version
```

## 2. 桌面端使用

### 2.1 首次配置

1. 打开 RunPHP，进入 **「设置」** 页面
2. 点击 **「下载安装」** 获取 FrankenPHP 运行时
3. 安装完成后，运行时版本会显示在列表中

### 2.2 创建站点

1. 进入 **「站点」** 页面，点击 **「+ 新建站点」**
2. 填写信息：

| 字段 | 说明 |
|---|---|
| **名称** | 站点显示名（如「我的博客」） |
| **域名** | 多个域名用逗号分隔（如 `blog.test, www.blog.test`） |
| **根目录** | 网站文件存放路径 |
| **端口** | 留空则由 Caddy 自动分配（80/443） |
| **HTTPS** | 开启后使用 Caddy 内置 CA 自动签发本地证书 |
| **Worker 模式** | Laravel / Symfony 等框架启用常驻进程 |

3. 点击 **「创建」**

### 2.3 启动服务

1. 进入 **「仪表盘」**，点击 **「启动服务」**
2. 状态变为 **「运行中」** 后，浏览器访问站点域名
3. 如需添加 hosts 记录，进入 **「Hosts」** 页面点击 **「同步站点域名」**

### 2.4 HTTPS 证书信任

启用 HTTPS 的站点首次访问时，Caddy 会自动安装本地 CA 根证书到系统信任库。

| 平台 | 行为 |
|---|---|
| **Windows** | 自动安装（可能弹出 UAC 确认） |
| **Linux** | 需手动执行提权命令（Hosts 页面有复制按钮） |

### 2.5 数据库管理

#### SQLite（内置）

1. 进入 **「数据库」** 页面
2. 点击 **「+ 新建数据库」**，输入名称
3. 在左侧选择数据库 → 中间选择表 → 右侧 SQL 编辑器
4. 输入语句，点击 **「执行 SQL」**

#### MySQL / MariaDB / PostgreSQL / MongoDB / Redis / Qdrant（远程连接）

1. 点击 **「+ 添加连接」**
2. 选择类型（MySQL / PostgreSQL / MongoDB / Redis / Qdrant），填写连接信息（主机 / 端口 / 用户名 / 密码 / 数据库）
3. 点击 **「测试」** 验证连接 → **「保存」**
4. 对于 MySQL / PostgreSQL 连接，可点击 **「浏览」** 进入表浏览与 SQL 执行器（操作方式与 SQLite 一致：左侧选表、右侧执行 SQL）
5. MongoDB / Redis / Qdrant 仅支持连接测试，不支持表浏览

### 2.6 热重载

站点变更（新增 / 修改 / 删除）后：

| 端 | 操作 |
|---|---|
| 桌面端 | 自动重新生成 Caddyfile，点击 **「热重载配置」** 生效 |
| CLI | 执行 `runphp reload` |

> 热重载不中断已有连接，新配置立即生效。

## 3. 无头服务器模式

### 3.1 基本操作

```bash
# 创建站点
runphp site add myapp --domain myapp.test --root /var/www/myapp --https

# 同步 hosts
runphp hosts sync

# 启动服务
runphp run

# 查看状态
runphp status

# 查看运行时日志（默认最近 100 行）
runphp logs
runphp logs --lines 300

# 设置默认运行时版本
runphp runtime default 1.12.7
```

### 3.2 Web 管理面板

```bash
# 启动面板（默认仅本地访问）
runphp panel --port 9080

# 允许外部访问（配合鉴权）
runphp panel --port 9080 --host 0.0.0.0 --token mySecret123
```

浏览器访问 `http://服务器IP:9080`，界面与桌面端完全一致。

### 3.3 systemd 服务

```bash
# 生成服务单元
runphp service-install

# 按提示执行（需 root）
sudo cp /tmp/runphp.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now runphp

# 查看日志
sudo journalctl -u runphp -f
```

## 4. 常见问题

### Q1: 启动服务失败，提示端口被占用？

FrankenPHP 默认监听 80 和 443 端口。请确保这些端口未被其他程序（如 Nginx、Apache）占用，或为站点指定其他端口。

### Q2: HTTPS 访问提示证书不安全？

首次使用 HTTPS 时，Caddy 会安装本地 CA 证书。如未自动安装，在 Hosts 页面查看提权命令并手动执行。

### Q3: hosts 同步提示无权限？

| 平台 | 需要的权限 | 获取提权命令 |
|---|---|---|
| Windows | 管理员 | `runphp hosts elevation` |
| Linux | root | `runphp hosts elevation` |

### Q4: 如何切换 PHP 版本？

FrankenPHP 每个发布版本内置固定的 PHP 版本。安装多个运行时版本后，通过以下命令切换默认版本（桌面端在「设置」页面的运行时列表点击「设为默认」）：

```bash
runphp runtime install 1.11.0
runphp runtime default 1.11.0
```

### Q5: Web 面板如何安全暴露到公网？

```bash
runphp panel --host 0.0.0.0 --port 9080 --token <随机长字符串>
```

> 建议配合反向代理（Nginx / Caddy）添加 HTTPS 和访问控制。
