## 1. 安装

### 1.1 桌面端

#### Windows

1. 下载 `RunPHP_0.1.0_x64-setup.exe`
2. 双击安装（如提示 SmartScreen，点击「仍要运行」）
3. 首次启动后会引导下载 FrankenPHP 运行时（约 60MB）

#### Linux

1. 下载 `RunPHP_0.1.0_amd64.AppImage` 或 `.deb`
2. AppImage 方式：
   ```bash
   chmod +x RunPHP_*.AppImage
   ./RunPHP_*.AppImage
   ```
3. deb 方式：
   ```bash
   sudo dpkg -i RunPHP_*.deb
   ```

### 1.2 无头服务器

```bash
# 下载 CLI 二进制
curl -L https://github.com/lopinx/runphp/releases/latest/download/runphp-linux-x86_64 -o runphp
chmod +x runphp

# 安装运行时
./runphp runtime install 1.12.7

# 验证
./runphp version
```

## 2. 桌面端使用

### 2.1 首次配置

1. 打开 RunPHP，进入 **「设置」** 页面
2. 页面会自动执行 **本地环境检测**：若本机已安装 FrankenPHP（PATH 中可见），会列出其路径并提供 **「导入使用」** 按钮，无需重新下载；同时探测本机 MySQL / PostgreSQL / MongoDB / Redis / Qdrant 默认端口，运行中的服务提供 **「添加连接」** 跳转链接
3. 若本机没有 FrankenPHP，在版本下拉列表中选择要安装的版本（自动从 GitHub Releases 拉取，新版本在前；也可手动输入版本号），点击 **「下载安装」**
4. 安装完成后，运行时版本会显示在列表中

### 2.2 创建站点

1. 进入 **「站点」** 页面，点击 **「+ 新建站点」**
2. 填写信息：

| 字段 | 说明 |
|---|---|
| **名称** | 站点显示名（如「我的博客」） |
| **域名** | 多个域名用逗号分隔（如 `blog.test, www.blog.test`） |
| **根目录** | 网站文件存放路径，可直接填写，也可点「浏览」可视化选择目录 |
| **端口** | 留空则由 Caddy 自动分配（80/443） |
| **HTTPS** | 开启后使用 Caddy 内置 CA 自动签发本地证书 |
| **Worker 模式** | Laravel / Symfony 等框架启用常驻进程 |

3. 点击 **「创建」**

### 2.3 启动服务

1. 进入 **「仪表盘」**，点击 **「启动服务」**
2. 状态变为 **「运行中」** 后，浏览器访问站点域名
3. 如需添加 hosts 记录，进入 **「Hosts」** 页面点击 **「同步站点域名」**

### 2.4 HTTPS 证书信任

启用 HTTPS 的站点首次访问时，Caddy 会自动安装本地 CA 根证书到系统信任库。

| 平台 | 行为 |
|---|---|
| **Windows** | 自动安装（可能弹出 UAC 确认） |
| **Linux** | 需手动执行提权命令（Hosts 页面有复制按钮） |

### 2.5 数据库管理

数据库页提供两个 Tab：**「服务」（默认，服务端管理）** 与 **「连接」（远程客户端）**。

#### 数据库服务托管（服务端管理）

把本机的 MySQL / MariaDB / PostgreSQL / Redis 纳入 RunPHP 托管，支持启停、建库建用户、改密与日志查看：

1. 进入 **「数据库」→「服务」** Tab，点击 **「检测」** 扫描本机已有服务（PATH、安装目录、系统服务、默认端口）
2. 检测结果可一键 **「接管」**（登记为托管服务，启停走系统服务）；或点击 **「导入」** 登记本地二进制为便携实例（不复制文件，数据落在 RunPHP 数据目录）；也可从 **「下载」** 预置源在线安装（MariaDB / PostgreSQL / Redis Windows 版）
3. 首次启动便携实例时自动初始化数据目录（MySQL `--initialize-insecure` / PostgreSQL `initdb` / Redis 免初始化）
4. 服务启动后可展开管理：**建库 / 删库、建用户 / 删用户 / 改密、root 改密**（Redis 为 `requirepass` 配置）
5. 点击 **「在连接页打开」** 自动注册连接档案，复用表浏览与 SQL 执行器
6. 站点编辑弹窗中可将站点与服务的数据库 **关联绑定**

> Windows 下「接管」系统服务启停需管理员权限，失败时会明确提示；建议无权限时改用便携导入。设置页「环境管理」提供各服务端口 / 自启 / 启停的简单配置卡片。

CLI 等价命令：

```bash
runphp db-service list            # 列出托管服务
runphp db-service detect          # 检测本机可接管/导入的服务
runphp db-service start <id>      # 启动
runphp db-service stop <id>       # 停止
runphp db-service dbs <id>        # 列出数据库
runphp db-service create-db <id> --name myapp
runphp db-service create-user <id> --username u1 --password p1 --database myapp
```

#### SQLite（内置）

1. 进入 **「数据库」** 页面
2. 点击 **「+ 新建数据库」**，输入名称
3. 在左侧选择数据库 → 中间选择表 → 右侧 SQL 编辑器
4. 输入语句，点击 **「执行 SQL」**

#### MySQL / MariaDB / PostgreSQL / MongoDB / Redis / Qdrant（远程连接）

切换到 **「连接」** Tab：

1. 点击 **「+ 添加连接」**
2. 选择类型（MySQL / PostgreSQL / MongoDB / Redis / Qdrant），填写连接信息（主机 / 端口 / 用户名 / 密码 / 数据库）
3. 点击 **「测试」** 验证连接 → **「保存」**
4. 对于 MySQL / PostgreSQL 连接，可点击 **「浏览」** 进入表浏览与 SQL 执行器（操作方式与 SQLite 一致：左侧选表、右侧执行 SQL）
5. MongoDB / Redis / Qdrant 仅支持连接测试，不支持表浏览

### 2.6 热重载

站点变更（新增 / 修改 / 删除）后：

| 端 | 操作 |
|---|---|
| 桌面端 | 自动重新生成 Caddyfile，点击 **「热重载配置」** 生效 |
| CLI | 执行 `runphp reload` |

> 热重载不中断已有连接，新配置立即生效。

## 2.7 FTP 管理

FTP 页提供两个 Tab：**「服务端」（默认，本机 FTP 服务管理）** 与 **「远程文件」（远程客户端）**。

### FTP 服务端

在本机提供 FTP 服务并管理虚拟用户（Linux 优先对接系统 Pure-FTPd；Windows 及未检测到 pure-ftpd 的环境自动使用内嵌 FTP 服务端）：

1. 进入 **「FTP」→「服务端」** Tab，点击 **「启动」**（默认端口 21，被动端口区间 50000–50010，均可在设置页或本页配置）
2. **虚拟用户管理**：添加用户（用户名 / 密码 / 主目录，可关联站点），每个用户 chroot 到自己的主目录，默认 `数据目录/ftp/<用户名>`
3. 勾选 **「随面板/应用自启」** 后服务随 RunPHP 启动
4. 客户端即可用 `ftp://127.0.0.1` + 虚拟用户凭据连接上传下载

CLI 等价命令：

```bash
runphp ftpd status               # 查看服务状态与后端
runphp ftpd start                # 以守护进程方式启动
runphp ftpd run                  # 前台运行（配合 systemd / 服务托管）
runphp ftpd stop                 # 停止
runphp ftpd user-list            # 列出虚拟用户
runphp ftpd user-add u1 --password p1 [--home D:\ftp\u1] [--site myapp]
runphp ftpd user-rm <id>
```

> Linux 下以非 root 运行且需绑定 21 端口时，可改用高位端口或以 root / `setcap` 授权。

### 远程文件（客户端）

支持 FTP / SFTP / FTPS 三种协议的远程文件管理，桌面端和 CLI 均可使用。

### 桌面端

在「FTP」页面可添加连接档案（含协议、主机、端口、认证方式），管理远程文件：

- 浏览目录（面包屑导航 + 双击进入子目录）
- 上传文件 / 上传文件夹（递归）、下载、删除、重命名、新建文件夹
- 上传/下载进度条实时显示（桌面端独有，Web 面板无进度反馈）
- 编辑连接档案（无需删除重建）

### CLI

```bash
# 列出连接档案
runphp ftp list

# 添加连接（--protocol 可选 ftp/sftp/ftps）
runphp ftp add 生产服务器 --host ftp.example.com --protocol sftp --username root --key ~/.ssh/id_rsa

# 测试连接
runphp ftp test <id>

# 列出远程目录
runphp ftp ls <id> --path /var/www

# 上传文件 / 上传文件夹
runphp ftp upload <id> --local ./index.php --remote /var/www/index.php
runphp ftp upload-dir <id> --local ./project --remote /var/www/project

# 下载 / 删除 / 重命名 / 建目录
runphp ftp download <id> --remote /var/www/config.php --local ./
runphp ftp rmfile <id> --path /var/www/old --dir
runphp ftp rename <id> --from /var/www/a.php --to /var/www/b.php
runphp ftp mkdir <id> --path /var/www/newdir
```

> SFTP 认证：优先 SSH 私钥（`--key`），其次密码（`--password`）。FTP/FTPS 使用密码认证。

## 3. 无头服务器模式

### 3.1 基本操作

```bash
# 创建站点
runphp site add myapp --domain myapp.test --root /var/www/myapp --https

# 同步 hosts
runphp hosts sync

# 启动服务
runphp run

# 查看状态
runphp status

# 查看运行时日志（默认最近 100 行）
runphp logs
runphp logs --lines 300

# 设置默认运行时版本
runphp runtime default 1.12.7

# 数据库服务与 FTP 服务端管理（详见 2.5 / 2.7 的 CLI 命令）
runphp db-service detect
runphp ftpd start
```

> 托管服务与 FTP 服务端若开启自启，会随 `runphp run` / `runphp panel` 一并启动。

### 3.2 Web 管理面板

```bash
# 启动面板（默认仅本地访问）
runphp panel --port 9080

# 允许外部访问（配合鉴权）
runphp panel --port 9080 --host 0.0.0.0 --token mySecret123
```

浏览器访问 `http://服务器IP:9080`，界面与桌面端完全一致。

### 3.3 systemd 服务

```bash
# 生成服务单元
runphp service-install

# 按提示执行（需 root）
sudo cp /tmp/runphp.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now runphp

# 查看日志
sudo journalctl -u runphp -f
```

## 4. 常见问题

### Q1: 启动服务失败，提示端口被占用？

FrankenPHP 默认监听 80 和 443 端口。请确保这些端口未被其他程序（如 Nginx、Apache）占用，或为站点指定其他端口。

### Q2: HTTPS 访问提示证书不安全？

首次使用 HTTPS 时，Caddy 会安装本地 CA 证书。如未自动安装，在 Hosts 页面查看提权命令并手动执行。

### Q3: hosts 同步提示无权限？

| 平台 | 需要的权限 | 获取提权命令 |
|---|---|---|
| Windows | 管理员 | `runphp hosts elevation` |
| Linux | root | `runphp hosts elevation` |

### Q4: 如何切换 PHP 版本？

FrankenPHP 每个发布版本内置固定的 PHP 版本。安装多个运行时版本后，通过以下命令切换默认版本（桌面端在「设置」页面的运行时列表点击「设为默认」）：

```bash
runphp runtime install 1.11.0
runphp runtime default 1.11.0
```

### Q5: Web 面板如何安全暴露到公网？

```bash
runphp panel --host 0.0.0.0 --port 9080 --token <随机长字符串>
```

> 建议配合反向代理（Nginx / Caddy）添加 HTTPS 和访问控制。
